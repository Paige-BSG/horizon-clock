# 闹钟

在「设置 → 闹钟」添加、编辑、关闭或删除闹钟，最多保存 20 个。时间与日期使用设备本地时区，与主屏时钟一致。主屏日期下方显示下一次提醒，点击可打开闹钟设置。

## 重复规则

| 规则             | 行为                                                   |
| ---------------- | ------------------------------------------------------ |
| 工作日（含调休） | 普通周一至周五响铃，放假日跳过；周末调休上班时照常响铃 |
| 假日（含周末）   | 普通周末及官方放假日期响铃；周末调休上班时跳过         |
| 每天             | 每个本地日期响铃                                       |
| 仅一次           | 在选定的未来日期响铃；过期后显示「已结束」             |
| 自选星期         | 按选定星期响铃，不应用放假和调休规则                   |

日历依据国务院办公厅的全国性放假调休通知，不含企业排班、个人请假或地区性假期。

- 2026 年：[国务院通知](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)，[北京市政府转载](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)。
- 2027 年：[国务院通知](https://www.gov.cn/zhengce/content/202611/content_7085101.htm)，[国家林草局转载](https://www.forestry.gov.cn/lyj/1/szxx/20261105/695102.html)。

这两年的安排随应用保存，无需联网或账号。未覆盖年份不按周末规则猜测：该年的工作日、假日闹钟暂停，界面提示更新应用；每天、仅一次、自选星期仍可使用。进入未覆盖年份前 35 天也会显示提示。后续年度日历通过应用版本更新维护，没有自动联网更新日历的功能。

## 响铃与运行条件

闹钟需要桌面版 HORIZON 保持运行，设备不休眠，且系统音量与输出设备可用。浏览器仅预览设置，不响铃。关闭应用、关机、注销或系统休眠期间，不保证提醒；恢复后不会补响超过 1 分钟的闹钟。

原生计时线程执行提前计算的 35 天计划，不依赖界面在响铃时刷新。界面按小时、日期、时区和设置变化重建计划。此功能不创建系统定时任务，也不会改变全局电源、静音或系统音量设置。

内置铃声不依赖网络、网易云账号或正在播放的歌曲，使用现有 mpv 运行依赖。播放器音量为 70%，实际声音还受系统音量、静音和音频输出影响。可先点「试听铃声」播放 5 秒。响铃窗口提供「停止闹钟」和「5 分钟后提醒」；正常响铃最多持续 3 分钟。多个同时到点的闹钟合并显示并使用同一铃声。播放失败时显示错误，不能把窗口出现视为声音已播放。

稍后提醒仅在当前应用进程中保留；退出或重启会取消。关闭或删除对应闹钟也会取消它的稍后提醒。

## 保存与备份

闹钟随本机设置保存，重启后恢复。导出设置包含闹钟，导入后全部保持关闭，需要逐个开启。旧设置文件不含闹钟时，导入结果为空列表；原有显示设置迁移规则不变。

## 验证范围

日历判断、重复计划、同时响铃去重、取消及设置保存由自动测试覆盖。浏览器测试使用原生命令替身检查交互，不能证明真实音频输出。实际 Omarchy / Surface 扬声器、静音与输出切换、后台运行、退出清理仍需目标设备验收。
