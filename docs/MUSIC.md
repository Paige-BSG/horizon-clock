# 音乐

HORIZON 只提供网易云音乐原生播放。右上角音乐图标统一展开、收起播放器，或按 `M` 切换。播放器内不显示来源标题和关闭按钮。左侧是音乐，右侧保留时间、日期与天气，比例为4:6；窄屏上下排列。

## 登录与歌单

首次使用点开底部「选歌」图标，选择「登录网易云」，进入「设置 → 应用 → 网易云音乐」。点击「扫码登录」，用手机网易云音乐 App 扫描 HORIZON 中的二维码并确认。二维码最多等待3分钟，过期后手动重新生成。取消或关闭设置会停止待确认二维码的检查。已登录的设备会恢复自己的歌单，不会自动播放；退出登录与失败重试也在这里。

上半区展示歌曲、歌手、状态与真实声纹，或显示歌曲列表。底部先放进度和五个播放按键，再放选歌、当前播放列表与音量三个图标。点开「选歌」后，菜单提供「我的歌单」和「随心听」，未登录时提供「登录网易云」。选择「我的歌单」后选择歌单和歌曲；选曲后列表保持展开，可从选歌菜单选择「返回播放」回到歌曲与声纹。菜单选择后自动收起，点击外部或按「Esc」也可收起；支持方向键、Home/End 和 Tab，单独打开菜单不会开始播放。歌单独立滚动，加载更多位于列表末尾。每页载入100首；最多读取账号的1000个歌单。

## 播放控制

主按键从左到右为随机、上一首、播放/暂停、下一首、循环。随机与循环分别控制，开启时显示强调色与圆点。循环按钮依次切换列表循环、单曲循环、关闭循环；单曲循环显示数字1，默认列表循环。两项偏好保存在本机，兼容原有模式设置，重启不会自动播放。单曲循环影响自然播完；手动上一首/下一首仍切换歌曲。关闭循环时，在整份歌单或本轮随机播放结束后停止。跨过当前页末尾会自动载入下一页。

开启随机不会立刻换歌；下一首或自然播完时，先载入整份歌单，再选择随机歌曲。一轮内不重复，开启列表循环时轮次交界处避免连续同一首；只有一首时依照循环开关重复或停止。上一首返回实际听过的歌曲，随后下一首可以沿原历史前进。载入失败时显示错误，不以当前100首冒充整份歌单。

右下方列表图标打开当前歌曲集合，可直接选曲；它与「我的歌单」的选择入口分开。当前列表按歌单或推荐的原始次序展示，不预告随机播放的后续顺序。浏览另一歌单不会改变当前播放列表、上一首/下一首或自然播完后的续播；点选其中歌曲后才切换播放列表。音量图标打开滑杆，点击外部或按「Esc」收起。歌曲进度显示已播放时间、总时长和进度线，当前不支持拖动定位。

「Esc」先收起选歌菜单或音量调节，再从列表返回播放画面，最后收起音乐。收起面板、浏览歌单或切换窗口时，主动开始的音乐继续播放。后台状态查询期间的播放操作按点击顺序执行。刷新或退出时钟会停止本应用拥有的播放器。重启、恢复登录和重新展开都不会自动开始一首新歌。

歌曲不可用、账号权限不足或只返回试听音源时显示错误，不自动跳过或改用其他音源。当前使用普通128kbps接口，不承诺会员、高音质或全曲库可用。歌曲名称和歌手显示为文本；不加载网易云网页、封面或下载歌曲。

## 随心听

「选歌」菜单中的「随心听」调用网易云私人FM推荐，不局限于当前歌单。点击后获取并播放账号推荐的歌曲，下一首或自然播完时继续，当前批次结束后再获取推荐。推荐模式按服务返回顺序播放，随机与循环按钮暂不可用；从自己的歌单中点选歌曲开始播放后恢复原随机和循环设置。近期推荐队列最多保留100首供回退。

没有推荐、接口受限或歌曲权限不足时会提示，不改用其他音源，也不绕过试听限制。该入口不恢复被移除的网络电台。推荐获取失败时保留原播放；歌曲本身不可播时停止该次播放。服务可用性依赖账号与网易云接口。

## 声纹

播放画面使用当前音频的64点时域波形。未播放、暂停或静音时显示直线，不持续绘图。「设置 → 显示 → 声纹动效」可暂停或开启；系统减少动态效果时初始静止。浏览歌单、收起播放器或窗口进入后台会停止绘制和原生分析，音频播放继续。分析不可用时显示直线和短提示。

Omarchy 使用现有 `pactl` 和 `parec`，只监测本应用及其子进程的唯一播放流，将其对应输出监测源与 `--monitor-stream` 同时固定。前端不能指定进程、流或设备。匹配不唯一时拒绝监测，不回退到全系统声音或麦克风。原始样本只在内存中计算，前端仅接收降采样的声纹和音量数据。

## 平台与账号

Linux 需要本机 `mpv`、PulseAudio兼容输出和已解锁的 Secret Service（如 GNOME Keyring）。缺少组件时提示，不自动安装。macOS 使用系统钥匙串，仍需 mpv；实际播放验证针对 aw-omarchy，其他平台未作听音验收。网页预览显示「桌面版可用」，不提供网页播放器。

登录凭据仅保存在系统钥匙串；无明文后备文件，不进入网页存储、设置导出、日志或播放器参数。沿用已确认的系统服务 `io.github.paige-bsg.horizon-clock.netease-probe` / `netease-session`，不复制或迁移。退出登录停止播放并移除 HORIZON 本机会话，不修改云端歌单或其他客户端登录。

原生适配使用固定版本 ncm-api-rs，无HTTP后台服务器。账号API在原生进程中请求，音频地址通过本机私有IPC交给本应用拥有的mpv，不传给网页或写入普通文件。系统TLS验证保持启用，不导入其他客户端凭据，不绕过付费或试听限制。打开音乐或账号设置后才请求恢复登录与歌单；没有自动播放。

旧电台偏好不再读取；现有显示、天气、背景设置与网易云钥匙串会话继续保留。音乐和服务权利属于各自权利人，不随 HORIZON 的MIT代码许可重新授权。验证记录见 [VALIDATION.md](VALIDATION.md)。
