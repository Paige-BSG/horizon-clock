# 音乐

在主屏点击音符按钮，或按 `M`，展开音乐模式。选择频道后点击「播放电台」，即可在时钟内收听。无需账号、网易云客户端或另一个浏览器窗口。

## 日常使用

- 三个预置频道：舒缓（Mellow Mix）、静谧（Serenity）、随心（Main Mix），均来自 Radio Paradise 官方公开流。
- 点击播放才连接电台。默认音量为30%，可以调整到静音。频道和音量保存在当前设备，重启后保留，但不会自动播放。
- 直播由电台编排，不支持搜索、单曲点播、上一首或回放。直接点击「舒缓」「静谧」「随心」切换频道。当前频道会高亮显示。播放中换台会先释放旧连接，再播放新频道。
- 点击「停止电台」会断开音频连接。再次播放从当前直播开始，不从之前停止的位置续播。
- 收起播放器或切换到其他窗口时，主动开始的音乐继续播放。`Esc` 收起播放器；退出或刷新时钟会停止播放。
- 中断后最多重试3次，间隔分别为2、5、10秒。连接或缓冲超过15秒视为失败；持续正常播放30秒后恢复重试额度。失败后可以手动再试或换台，停止会取消重连。

## 画面与动效

音乐模式在主屏按左4、右6分栏：左侧保留频道、声纹、播放/停止、音量和来源，右侧重新排布原有时间、日期和天气。原有时钟仍持续更新，设置、背景、全屏和夜间按钮保持可用。小屏改为上下排布，优先保留信息可读性。收起后恢复原时钟布局，已主动开始的音乐继续播放。

声纹直接使用当前音频的64点时域波形，并用实际音量包络调整幅度和光强。停止、未播放或静音时立即显示一条直线，不保留球体、旋转或预设节拍；此时不持续绘图。右下角可暂停或恢复声纹动效。系统开启减少动态效果时初始静止，可主动开启。收起播放器、暂停动效或窗口进入后台会停止绘制与原生音频分析。分析不可用时收成直线并显示短提示。

Omarchy 通过现有 `pactl` 和 `parec` 读取**本应用进程或其子进程的唯一播放流**，将其对应输出监测源与 `--monitor-stream` 同时固定；不能由前端指定进程、流或设备。没有唯一归属或正确监测源时拒绝监测，不回退到全系统输出或麦克风。原始样本仅在内存中计算，随后丢弃；前端只收到音量、频段和降采样的64点声纹数据。停止、换台、收起与退出都会终止对应监测进程。实现依据 [PulseAudio 的指定播放流监测接口](https://freedesktop.org/software/pulseaudio/doxygen/stream_8h.html)。

网页预览使用 Web Audio 分析其媒体元素。外部电台的跨域限制可能令网页分析失败；[Web Audio 规范](https://www.w3.org/TR/webaudio-1.1/)禁止跨域媒体样本泄露。Omarchy 的原生节奏通道保持现有媒体播放方式，不依赖更改电台跨域策略。其他桌面平台的原生节奏监测尚未实现，不声明已通过验证。

## 网络与来源

音频由时钟内置的浏览器音频组件直接从 Radio Paradise 接收。展开音乐模式和选择频道本身不联网；点击播放才发送音频请求。服务方可见设备的网络地址。请求采用浏览器媒体加载和无来源页策略。连接由系统 Webview 管理，服务方可能使用服务 Cookie；电台来源不提供账号登录，也不读取或导入 Cookie。

只使用内置的 HTTPS 流地址，不接受任意音频网址。不提供歌曲下载、录音、离线缓存或重新分发，也不请求专辑封面、歌单或曲库接口。`horizon-radio-v1` 只保存频道标识和音量，不保存播放意图；它独立于显示设置备份。

Radio Paradise 官方提供[供收音机和其他播放器使用的地址](https://radioparadise.com/listen/stream-links)，[官方帮助页](https://apps.radioparadise.com/rp3.php?name=Help)说明收听不需要注册。界面的来源链接可打开官方页面。音频和电台名称属于各自权利人，不随 HORIZON 的 MIT 代码许可重新授权；这里提供的是个人直接收听入口，不是曲库分发授权。

## 平台与验证

网页预览与桌面版使用同一套播放逻辑，无新增 JavaScript 库。电台复用已有系统音频工具；网易云的原生依赖见下文。电台的 Linux 桌面实际解码能力由 WebKitGTK/GStreamer 提供；需要 `gst-plugins-good` 与 `gst-libav` 等对应运行组件。展开电台时会先检查本机音频输出组件，缺失时禁用播放并显示提示。网络可达、媒体解码、界面状态和用户实际听到的声音是不同层面的验证，记录在 [VALIDATION.md](VALIDATION.md)。不保证任何外部直播服务始终在线；时钟本身在无网时仍可使用。

## 网易云音乐（桌面版）

展开音乐后选择「网易云」。已登录的设备会恢复自己的歌单，但不会自动播放。首次使用点击「扫码登录」，直接在 HORIZON 内显示二维码；用手机网易云音乐 App 扫描并确认。二维码最多等待 3 分钟，过期后由用户手动重新生成。取消或切换到电台后停止扫码检查。

选择歌单，再点击歌曲开始播放。支持暂停、继续、上一首、下一首、音量和播放进度显示。自然播完后播放当前已载入列表的下一首；最后一首结束后停止。每页载入 100 首，可点击「加载更多」。最多读取账号的 1000 个歌单。歌曲不可用、账号权限不足或只返回试听音源时显示错误，不自动跳过，也不改用其他音源。当前使用普通 128 kbps 接口，不承诺会员、高音质或全曲库可用。

两种来源互斥：切换来源会停止上一种来源。收起面板后音乐继续；刷新页面或关闭窗口会停止本应用拥有的播放器。启动和恢复登录都不会自动播放。歌曲名称和歌手来自服务返回数据；界面只显示文本，不加载服务提供的网页或封面。

Linux 需要系统已安装的 `mpv`、PulseAudio 兼容输出，以及已解锁的 Secret Service（如 GNOME Keyring）。缺少组件时给出提示，不自动安装。macOS 使用系统钥匙串，仍需 mpv；本次实际平台验证针对 aw-omarchy，其他平台未作听音验收。网页预览只显示「桌面版可用」。

登录凭据仅保存在系统钥匙串；无明文后备文件，不进入网页存储、设置导出、日志或播放器参数。为连续使用已确认的验证会话，沿用系统服务 `io.github.paige-bsg.horizon-clock.netease-probe` / `netease-session`，直接在原处读取，不复制或迁移。点击「退出登录」停止播放并移除该 HORIZON 本机会话，不修改云端歌单或其他客户端的登录。

原生接口适配使用固定版本的 ncm-api-rs，无 HTTP 后台服务器。账号 API 在原生进程内请求，签名音频地址通过本机私有 IPC 交给本应用拥有的 mpv 子进程，不传给网页或写入普通文件。系统默认网络身份、TLS 验证保持启用；不伪造 IP，不导入其他客户端凭据，不绕过付费或试听限制。Linux 声纹沿用严格的本应用子进程音频流检测；匹配不唯一时显示分析不可用，不采集麦克风或全系统声音。
