# 网络电台

在主屏点击音符按钮，或按 `M`，展开网络电台。选择频道后点击「播放电台」，即可在时钟内收听。无需账号、网易云客户端或另一个浏览器窗口。

## 日常使用

- 三个预置频道：舒缓（Mellow Mix）、静谧（Serenity）、随心（Main Mix），均来自 Radio Paradise 官方公开流。
- 点击播放才连接电台。默认音量为30%，可以调整到静音。频道和音量保存在当前设备，重启后保留，但不会自动播放。
- 直播由电台编排，不支持搜索、单曲点播、上一首或回放。直接点击「舒缓」「静谧」「随心」切换频道。当前频道会高亮显示。播放中换台会先释放旧连接，再播放新频道。
- 点击「停止电台」会断开音频连接。再次播放从当前直播开始，不从之前停止的位置续播。
- 收起控制栏或切换到其他窗口时，主动开始的音乐继续播放。`Esc` 优先收起控制栏；退出或刷新时钟会停止播放。
- 中断后最多重试3次，间隔分别为2、5、10秒。连接或缓冲超过15秒视为失败；持续正常播放30秒后恢复重试额度。失败后可以手动再试或换台，停止会取消重连。

## 网络与来源

音频由时钟内置的浏览器音频组件直接从 Radio Paradise 接收。展开控制栏和选择频道本身不联网；点击播放才发送音频请求。服务方可见设备的网络地址。请求采用浏览器媒体加载和无来源页策略。连接由系统 Webview 管理，服务方可能使用服务 Cookie；HORIZON 不提供账号登录，也不读取或导入 Cookie。

只使用内置的 HTTPS 流地址，不接受任意音频网址。不提供歌曲下载、录音、离线缓存或重新分发，也不请求专辑封面、歌单或曲库接口。`horizon-radio-v1` 只保存频道标识和音量，不保存播放意图；它独立于显示设置备份。

Radio Paradise 官方提供[供收音机和其他播放器使用的地址](https://radioparadise.com/listen/stream-links)，[官方帮助页](https://apps.radioparadise.com/rp3.php?name=Help)说明收听不需要注册。界面的来源链接可打开官方页面。音频和电台名称属于各自权利人，不随 HORIZON 的 MIT 代码许可重新授权；这里提供的是个人直接收听入口，不是曲库分发授权。

## 平台与验证

网页预览与桌面版使用同一套播放逻辑，无新增 JavaScript 或 Rust 库依赖。Linux 桌面实际解码能力由 WebKitGTK/GStreamer 提供；需要 `gst-plugins-good` 与 `gst-libav` 等对应运行组件。展开电台时会先检查本机音频输出组件，缺失时禁用播放并显示提示。网络可达、媒体解码、界面状态和用户实际听到的声音是不同层面的验证，记录在 [VALIDATION.md](VALIDATION.md)。不保证任何外部直播服务始终在线；时钟本身在无网时仍可使用。
