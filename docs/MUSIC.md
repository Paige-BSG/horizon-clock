# 音乐控制

在主屏点击音符按钮，或按 `M`，展开音乐控制栏。可以查看当前歌名、歌手和播放状态，并使用播放/暂停、上一首、下一首。音乐栏展开时仍显示时钟、日期和天气；收起后恢复原有时间字号。`Esc` 优先收起音乐栏。

## 首次连接

1. 在运行 HORIZON 的同一台 Linux 设备、同一桌面会话中，打开网易云官方播放器。也可以使用支持系统媒体控制的浏览器打开网易云官方网页。
2. 在官方播放器中登录、选择歌单并开始播放一首歌。保持播放器或网页标签页运行。
3. 回到 HORIZON，展开音乐控制栏。只有一个可用播放器时自动连接；检测到多个时，需要先选择要控制的播放器。
4. 之后可以在时钟内暂停、继续播放和切歌，无需反复切换应用。登录、搜索、歌单管理和会员购买仍在官方播放器中完成。

播放器必须提供 Linux 的 MPRIS 系统媒体接口。未提供接口的客户端或网页不会出现在列表中；HORIZON 不保证所有版本的网易云播放器或浏览器均可联动。部分播放器不支持切歌，对应按钮会禁用。名称由播放器提供，HORIZON 不验证其发行来源。macOS 和普通浏览器预览会显示平台说明，不提供模拟播放功能。

## 断连与刷新

- 音乐栏展开且 HORIZON 页面可见时，每次读取完成后等待 3 秒刷新。收起或页面隐藏后停止刷新，官方播放器中的音乐继续播放。
- 切换播放器只改变控制目标，不会自动暂停或启动任一播放器。
- 播放器退出、重新启动或连接失败时禁用旧连接。不会自动改为控制另一个播放器；在列表中明确选择新连接后才能继续操作。
- 指令发送期间禁用重复操作。完成后读取播放器的实际状态；失败时提示重试，不预先显示成功。

## 账号与内容边界

HORIZON 通过本机 D-Bus 读取状态并发送有限的播放指令，不接入网易云的账号或曲库接口，不保存密码、登录 Cookie、歌曲音频或下载链接。播放器选择只保留在当前应用会话中，不写入设置备份。HORIZON 不请求封面、歌词或外部音频资源，不增加音乐相关外网连接。

账号、会员、曲目可用性、地区和服务授权由官方播放器及服务条款决定。系统媒体控制不会为 HORIZON 增加曲库授权，也不提供破解会员或跨地区解锁能力。

实现使用现有 Linux `zbus` 依赖。`serde` 用于桌面接口的数据序列化，是现有依赖树中已经使用的库。测试通过独立的本地 D-Bus 对等连接模拟播放器，不需要安装或修改系统 D-Bus 服务。

接口依据：[MPRIS 标准](https://specifications.freedesktop.org/mpris/latest/)、[播放器控制与能力属性](https://specifications.freedesktop.org/mpris/latest/Player_Interface.html)。
