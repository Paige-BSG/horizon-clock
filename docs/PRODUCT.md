# HORIZON 产品定义

HORIZON 是面向墙面平板的环境时钟。用户在客厅远处看清时间，靠近时可以调整风景、天气和昼夜显示。已确认的设计是产品的界面基线。

首个目标平台是 Omarchy 4.5。先验证 x86_64 设备；其他系统及架构的构建结果不等于获得正式支持。

## 第一版行为

| 场景           | 应有行为                                                           |
| -------------- | ------------------------------------------------------------------ |
| 第一次打开     | 选择天气城市，决定是否联网获取天气、是否按时间调暗，再开始使用     |
| 日常显示       | 时间为第一视觉层级，日期与天气为辅助信息；显示设备的本地时间       |
| 更换风景       | 使用本地图片，缓慢切换，可暂停、手动换图或使用纯色                 |
| 夜间           | 按本地时间渐进调暗；手动调整在下一次昼夜边界恢复自动计划           |
| 天气服务失败   | 有缓存时明确标为缓存；没有缓存时显示暂不可用，不能永久停在加载中   |
| 无网络         | 时间、日期、背景、设置保持工作；过期天气不能当作新天气             |
| 关闭常亮或退出 | 释放应用持有的系统抑制请求，不改变全局电源和锁屏设置               |
| 安装与维护     | 有应用图标、用户自选登录启动、备份和卸载方式，维护文档说明升级行为 |

## 1.0 验收

另一位用户应能根据说明独立安装与设置。目标设备连续运行 72 小时，经过断网恢复、昼夜切换、系统重启、应用重启和版本更新后仍正常使用。视觉验收需要维护者与实际用户在观看距离确认。

界面渲染、网页测试、桌面编译、Linux 编译、目标平板运行和长期验收分别记录，不能互相替代。当前状态见 [VALIDATION.md](VALIDATION.md)。

## 当前边界

音乐采用可选的免登录网络电台，在时钟内直接播放。用户选择频道、播放/停止和音量；直播内容由电台编排，不提供单曲搜索或点播。点击播放才联网，每次启动都保持停止状态。音频来源及使用边界见 [网络电台](MUSIC.md)。

天气先提供东京、上海、北京、深圳、杭州五个城市。支持本地选择，不获取 GPS。免费 Open-Meteo 接口用于个人及非商业使用。未来商用发行需要明确天气服务授权。

当前更新按钮只查询正式版本信息。签名更新、回滚和可直接下载的正式 Linux 安装包须经过路线图中的发行检查后交付。
